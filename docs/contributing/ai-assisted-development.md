# AI-assisted development

Claude and Codex contributed substantially to ClearScout's implementation, tests,
and prose. I own the requirements, acceptance, review, release, support, and
every decision about what the program is allowed to claim.
[How it was built](agent-workflow.md) describes the setup.

Generated code gets the same welcome as a stranger's pull request: read,
tested, and doubted. Provenance, privacy, offline tests, no-unapproved-cost
rules, and license checks bind every change, whoever or whatever drafted it.
Tests and evaluations are controls, not a warranty that generated code or prose
is correct.

Contributors may use AI assistance. Disclose substantial use in the pull
request, review the output before submitting it, respect upstream licenses, and
keep real CVs, job-search records, provider responses, and secrets out of the
repository. [AGENTS.md](../../AGENTS.md) lists what an agent may not do without
the maintainer's explicit approval.
