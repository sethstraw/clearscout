How it works

Scanning and tracking are free and need no CV or provider key. Evaluation and drafting are separate, opt-in steps that run on your own OpenAI or Anthropic account.

FREE

Scan 47 kinds of job board

One reader per applicant tracking system reads each employer's own job feed. No reader calls a model, and each site's published policy decides what is read.

FREE

Screen and track

Deterministic rules screen every posting before any paid step. Scheduled scans land in one review queue, and each application keeps an append-only history.

PAID, OPT-IN

Evaluate and draft

A model compares a posting with your master CV and drafts a resume and cover letter. Nothing paid runs until a person starts it.

Every claim cites your record

Anti-fabrication is the point. A model may select and reorder CV evidence, but it may cite only evidence identifiers that exist in the CV selected for that run. The program copies titles, employers, dates, education, and publication citations verbatim. A deterministic reader reports its own reading of each posting beside the model's, and where they disagree, both are shown.

Install

Version 0.1.0 is an alpha for technical early adopters, checked on macOS and Ubuntu. Install uv, download the wheel and SHA256SUMS from the newest release, then verify and install it. 

shasum -a 256 -c --ignore-missing SHA256SUMS
gh attestation verify ./clearscout-*.whl --repo sethstraw/clearscout
uv tool install ./clearscout-*.whl

The README covers starting the app, the synthetic demo workspace, and known limits.
