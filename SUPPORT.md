# Support

Use GitHub issues for reproducible bugs and documentation problems. Remove real
CV text, job-search records, provider responses, API keys, and personal data
before posting.

Use GitHub private vulnerability reporting for security problems. If that route
is unavailable, open a public issue asking for a private contact method and do
not include exploit details or sensitive data.

Conduct concerns are covered by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

This is a single-maintainer project with no service-level agreement. TailorCV
does not provide individual career advice, application review, hiring advice, or
support for submitting applications.
