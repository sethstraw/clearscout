# Generated artifacts

The files this rule loads for are written by `scripts/generate.sh`, which names
the generator for each, so a hand edit to one is silently overwritten.

Change the source and regenerate with `scripts/generate.sh`. The
`generated-artifact-sentinel` skill maps generators to outputs and checks a
diff for a hand edit that will be overwritten.
